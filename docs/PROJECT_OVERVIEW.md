# Описание проекта

## Назначение

«Ансамблевый краткосрочный прогноз» - прикладная прогнозная система для нефтепромысловых данных. Она строит краткосрочный прогноз добычи жидкости, нефти и газа по отдельным скважинам и агрегированно по месторождению. Целевой горизонт из исходной проектной документации - до 3 месяцев, при этом более длинный прогноз возможен, но ожидаемо теряет точность.

Система объединяет несколько классов моделей:

- физико-математические модели фильтрации и пьезопроводности;
- CRM/CRMIP-модели межскважинного влияния;
- статистические и ML-модели временных рядов;
- сценарные расчеты ППТП/ГТМ;
- байесовский ансамбль, который взвешивает прогнозы отдельных моделей и формирует доверительный интервал.

## Основной поток данных

1. Пользователь выбирает месторождение, цеха, скважины и даты адаптации/прогноза.
2. `tools_preprocessor` читает таблицы месторождения из `tools_preprocessor/data/<месторождение>`.
3. Препроцессор фильтрует фонд, интервалы работы, мероприятия, ГДИС, координаты и исторические дебиты.
4. Выбранные модели получают подготовленные ряды по скважинам.
5. `UI/data_processor.py` приводит результаты разных моделей к единому табличному формату:
   - `<скважина>_liq_true`, `<скважина>_liq_pred`;
   - `<скважина>_oil_true`, `<скважина>_oil_pred`;
   - `<скважина>_gas_true`, `<скважина>_gas_pred`.
6. `models_ensemble` строит ансамблевый прогноз и доверительные интервалы.
7. `statistics_explorer` рассчитывает ошибки и строит графики для UI.
8. Streamlit-интерфейс показывает карту, графики по скважинам, аналитику и экспорт результатов.

## Архитектура каталогов

| Путь | Роль |
|---|---|
| `orchestrator/main_UI.py` | Главный Streamlit launcher. Инициализирует состояние, боковую панель, страницы и запуск расчетов. |
| `orchestrator/UI/pages` | Отдельные страницы приложения: настройки, карта, скважина, аналитика, ГТМ, импорт/экспорт. |
| `orchestrator/UI/cached_funcs.py` | Кэшируемые функции запуска моделей. |
| `orchestrator/UI/data_processor.py` | Нормализация результатов моделей, подготовка данных ансамбля и статистики. |
| `orchestrator/tools_preprocessor` | Чтение исходных таблиц, выбор рабочих скважин, подготовка входов для моделей. |
| `orchestrator/frameworks_ftor` | Модель пьезопроводности и адаптация параметров скважин. |
| `orchestrator/models_transflow_siam` | Низкоуровневое расчетное ядро transient-flow, numba/AOT-компиляция. |
| `orchestrator/frameworks_wolfram` | ML-прогнозы на ElasticNet, SVR, XGBoost и связанных признаках. |
| `orchestrator/frameworks_crm` | CRM/CRMIP, коэффициенты влияния нагнетательных и добывающих скважин. |
| `orchestrator/frameworks_hybrid_crm_ml` | Гибридный CRM/ML расчет через FEDOT. |
| `orchestrator/frameworks_shelf_algo` | ППТП/ГТМ, последние замеры, темпы падения, сценарные корректировки. |
| `orchestrator/models_ensemble` | PyMC3/Markov Chain Monte Carlo ансамбль и доверительные интервалы. |
| `orchestrator/models_waterflood` | Corey-модель обводненности. |
| `orchestrator/statistics_explorer` | Расчет ошибок, гистограмм, treemap и сравнительных графиков. |

## Входные данные

Ожидаемый набор данных для каждого месторождения лежит в:

```text
orchestrator/tools_preprocessor/data/<месторождение>/
```

Типовой набор файлов:

- `coord.feather` - координаты скважин;
- `fond.feather` - фонд скважин;
- `frac.feather` - ГРП/события;
- `merop.feather`, `mersum.feather` - мероприятия;
- `projectcoord.feather` - проектные координаты;
- `sh.feather`, `sh_sost_fond.feather`, `sost.feather` - история эксплуатации и состояния;
- `sppl.feather`, `troil.feather`, `welllist.feather`, `wellplast.feather` - параметры пластов, скважин и добычи;
- `gdis.xlsm` - ГДИС и дополнительные ограничения;
- `Input_data_CRM_<месторождение>.xlsx` - входы CRM для части месторождений.

В корне проекта находятся сохраненные состояния Streamlit-приложения в формате `*.pickle`. Их можно импортировать через страницу «Импорт/экспорт».

## Выходные данные

Основной выходной формат внутри приложения - словари `state.statistics`, где каждому имени модели соответствует `pandas.DataFrame` с фактами и прогнозами. UI умеет:

- показывать прогноз по отдельной скважине;
- показывать карту и treemap ошибок;
- строить статистику по моделям;
- экспортировать состояние приложения в `*.pickle`;
- экспортировать расчетные таблицы в `*.xlsx`.

## Важные технические замечания

- Проект исторически рассчитан на Python 3.8/3.9 и старые версии библиотек `streamlit`, `pymc3`, `theano`, `numba`, `fedot`.
- Локальные Python-окружения не включены в публикацию; зависимости необходимо установить отдельно.
- Для расчетного ядра `models_transflow_siam` нужен шаг AOT-компиляции `__compile_aot__.py`.
- Исходный `main_UI.py` в текущей копии был не Streamlit-приложением, а демонстрационным кодом маятника. Он заменен на launcher, который соответствует структуре `UI/pages` и найденной команде запуска.
